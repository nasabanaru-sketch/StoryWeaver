# StoryWeaver Live 操作・運用マニュアル (Operation Manual)

本ドキュメントは、**StoryWeaver Live** の起動前準備、起動手順、ブラウザUIでの基本操作、スタッフ設定の各項目、正常停止・トラブルシューティングまでを網羅した運用マニュアルです。

---

## 1. システム全体構成とポート番号

StoryWeaver Live は完全ローカル稼働型のマルチプロセスアーキテクチャです。起動前に各サービスの役割を確認してください。

| サービス | URL / ポート | 役割 | 起動コマンド / 起動元 |
| :--- | :--- | :--- | :--- |
| **ComfyUI** | `http://127.0.0.1:8188` | SDXL (Animagine XL 3.1) + IP-Adapter Plus Face 画像生成エンジン（InstantID/InsightFace は商用化のため 2026-10-26 に廃止） | Pinokio または ComfyUI bat スクリプト |
| **Ollama** | `http://127.0.0.1:11434` | VLM（外見・髪型・眼鏡等の特徴抽出） | `ollama serve`（常駐プロセス） |
| **FastAPI サーバー** | `http://127.0.0.1:8000` | パイプライン制御、音声感情解析、UI配信 | `python -m uvicorn server:app --host 0.0.0.0 --port 8000` |
| **フロントエンドUI** | `http://127.0.0.1:8000/` | 来場者用ウィザード＆スタッフ設定画面 | ブラウザ（Chrome / Edge 推奨） |

---

## 2. 起動手順（順番厳守）

GPUメモリ（VRAM 16GB）の競合を防ぎ、安全に起動するために以下の順番でプロセスを立ち上げてください。

### ステップ 1: ComfyUI の起動
1. Pinokio または ComfyUI の起動バッチを実行します。
2. ブラウザで `http://127.0.0.1:8188` を開き、ComfyUI の画面が表示されることを確認します。

### ステップ 2: Ollama の確認
1. コマンドプロンプトまたは PowerShell で以下を実行し、Ollama が起動していることを確認します。
   ```powershell
   ollama list
   ```
2. 対象モデル（`gemma4:e2b` など）が登録されていることを確認します。未起動の場合は `ollama serve` を実行します。

### ステップ 3 ＆ 4: 一括自動起動（推奨: ランチャー実行）
プロジェクトルートにある `start_storyweaver.bat`（または `start_storyweaver.ps1`）を実行するだけで、サーバーの別ウィンドウ起動、AIモデルのウォームアップ監視、ブラウザ起動まで全自動で行われます。

- **エクスプローラーから起動する場合**:
  `C:\antigravity\StoryWeaver\start_storyweaver.bat` をダブルクリックします。
- **PowerShell から起動する場合**:
  ```powershell
  cd C:\antigravity\StoryWeaver
  .\start_storyweaver.ps1
  # または .\start_storyweaver.bat
  ```

起動すると別ウィンドウ（`StoryWeaver Live Server`）でサーバーとAIモデル（SenseVoice / 12感情モデル）が立ち上がり、ヘルスチェック完了後にブラウザで `http://127.0.0.1:8000/` が自動オープンします。

> **手動で起動する場合（コマンドライン実行）**:
> 1. `python -m uvicorn server:app --host 0.0.0.0 --port 8000` を実行します。
> 2. `SenseVoiceSmall ロード完了` および `VoiceEmoAnalyzer ウォームアップ完了` が表示されたら、ブラウザで `http://127.0.0.1:8000/` を開いてください。

## 3. 来場者体験フロー（基本操作手順）

画面上の 5 ステップ・ウィザードに従って体験を進行します。

```text
[Step 1: シーン選択] ➔ [Step 2: カメラ撮影] ➔ [Step 3: 音声発声・セリフ確認] ➔ [Step 4: キャラクター召喚] ➔ [Step 5: アートカード完成]
```

### 【Step 1: シーン選択（＋AIモデル手動スタンバイ機能）】
- **⚡ AIモデルをスタンバイ（Gemma + Qwen2 事前ロード）ボタン**:
  - シーン選択画面の上部に設置された「**⚡ AIモデルをスタンバイ (Gemma + Qwen2 事前ロード)**」ボタンを手動で押すと、来場者が世界観を選んでいる間に裏側で `POST /api/models/standby` が実行されます。
  - 内部では ①前回の画像生成で残っている ComfyUI の待機 VRAM 解放（`/free`）➔ ②Ollama `gemma4:e2b` のプリロード（`keep_alive="15m"`）➔ ③`Qwen/Qwen2-Audio-7B-Instruct`（4bit）の VRAM ロードが順に行われます。
  - 非ブロッキング設計のため、ロード中であってもそのままシーンカードを選択して Step 2（カメラ撮影）へ進むことができます。
  - ※ Step 5 から「↻ もう一度あそぶ / 最初の画面へ」で Step 1 に戻った際は、自動でのスタンバイは行われません（Step 1 の手動ボタンを押したときのみ VRAM へ事前ロードされます）。
- 来場者に転生したい世界観（カード形式）を選択してもらいます（例：「覚醒の剣士」「サイバーパンク・ハッカー」など）。
- 選択すると「Step 2」へ自動遷移します。

### 【Step 2: カメラ撮影（Gemma 4 e2b ＆ Qwen2-Audio の VRAM 保持継続）】
- 画面中央のファインダーに頭部シルエットと肩ラインのガイドが表示されます。
- ガイド枠の中央に来場者の顔を合わせ、「**撮影する**」ボタンを押します（3秒カウントダウン後に撮影）。
- 撮影直後、サーバー側で「頭頂部の髪〜肩まで」の正方形領域へ自動クロップされた画像が大きくプレビュー表示されると同時に、裏側で非同期に外見特徴抽出（VLM: `gemma4:e2b`）が開始されます。
- **VRAM 保持仕様**: Step 2 の顔認識（`POST /api/analyze_face`）では、Step 1 でスタンバイ済みの `Qwen2-Audio` をアンロードせずそのまま維持し、顔認識を終えた `gemma4:e2b` も `keep_alive="15m"` によって VRAM 上に保持したまま Step 3 へ引き継ぎます（Step 3 での再ロード待ち時間をゼロにします）。
- 頭髪から肩までが適切に収まっていることを確認し、「**この写真で進む（セリフ録音へ） ➔**」を押すと「Step 3」へ進みます（見切れている場合は「**↺ 撮り直す（再撮影）**」で再撮影可能）。
- （※ 顔が枠外や暗闇で見つからない場合は「顔未検出アラート」が表示されるので、撮り直してください）

### 【Step 3: 音声発声・セリフ確認（＋棒読み測定 → 本番発声 2ステップ導線）】
- スタジオ画面上部に、現在使用中のクロップ済み顔写真のサムネイルが表示されます。
- **🎙️ 2ステップ音声導線（`detailed_12` / `qwen2_audio_hybrid` モード時）**:
  - **STEP 3-1：平常声（棒読み）の測定**:
    - 「まずは普段の平坦な声（棒読み）で『あー、マイクのテスト中です』またはセリフを軽く読んでください」という案内に従い、「**🎙 棒読みを測定する**」ボタンを押して録音（もう一度押して停止、最大6.0秒で自動停止）します。
    - 測定が完了すると `POST /api/calibrate_voice_emo` (`mode="normal"`) で基準登録され、「`✅ あなたの声の基準（ベースライン）を登録しました（F0: ○○Hz / 声量: ○○dB）`」バッジが表示されて STEP 3-2 がハイライトされます（「スキップして本番録音へ ➔」でスキップも可能）。
    - さらに精度を上げたい場合は、下の折りたたみパネル「**詳細ボイスチェック（任意：②張り声・③ささやきで精度アップ）**」から上限アンカー・吐息アンカーも登録できます。
  - **STEP 3-2：本番セリフの発声**:
    - 下部の大きな丸いマイクボタンをクリックして本番録音を開始し、役になりきってセリフを発声後、もう一度押して停止します。
    - `qwen2_audio_hybrid` モード時は推論中に「**AIが声の演技ニュアンスと物理変化を精密分析中...**」のオーブアニメーションと経過秒数が表示されます。
- **解析結果の確認**:
  - **従来モード (`standard`) 時**: `BURNING`（熱狂・叫び）、`JOYFUL`、`EMOTIONAL`、`COOL` 等の声量・感情バッジが表示されます。
  - **詳細感情モード (`detailed_12`) 時**: 基礎指標および15次元の音響物理特徴量（`z`ベクトル）とプロトタイプ辞書との重み付きユークリッド距離（Gaussian Similarity）＋ SenseVoice 感情タグボーナス（`+5.0pt`）から算出された「**第1階層：基本感情（6種から1つを排他選択）**」と「**第2階層：声質ニュアンス修飾（色気・照れの2種、条件未達時はストレート表現［修飾なし］）**」がビジュアルカードで表示されます。
  - **Qwen2-Audio + Gemma 4 ハイブリッドモード (`qwen2_audio_hybrid`) 時**: Step 1（`Qwen/Qwen2-Audio-7B-Instruct` 4bit による英語聴覚知覚）＋ 中間層（`baseline_deltas` からの英語 Semantic Bridge 変換）＋ Step 2（Ollama `gemma4:e2b` JSON Schema 0〜5整数採点 × 20）の2ステップ分析が実行され、専用結果パネル（`#result-qwen-container`）に以下の要素が表示されます（日本語コメント出力は廃止）：
    1. **Overall Impression バッジ (`overall_impression_en`)** と **選出された2階層感情カード（第1階層 PRIMARY ／ 第2階層 NUANCE ※60pt以上発動時のみ強調表示）**
    2. **棒読み基準からの物理変化メーター (`baseline_deltas`)**: 声量変化（dB）、ピッチ変化（半音）、抑揚（半音）、明るさ変化（Hz）、澄み具合（HNR dB）、息漏れ倍率（×倍）を中央基準（±0 / 1.0倍）からの左右インジケーターバーで可視化
    3. **8感情スコア一覧バー (`emotions_12`)**: 基本6感情と声質ニュアンス修飾2種（60pt発動閾値ライン付き）のスコアバー（0〜100pt、20点刻み）
- **セリフ修正**: 音声認識されたテキストが右側の入力欄に自動反映されます。キーボードで自由に打ち替えることも可能です。
- 「**この内容でキャラクターを召喚！ ➔**」をクリックします。

### 【Step 4: キャラクター召喚（生成中演出）】
- アニメーション魔法陣とプログレスバーが稼働し、画像生成パイプラインが実行されます。
- 通常約 2分（実測 125〜135秒程度。Gate 3 検証 2026-10-22）で生成が完了します。最大 7分まで許容しています。

### 【Step 5: アートカード完成 ＆ 保存・印刷（＋再生成・履歴機能）】
- 生成されたキャラクターイラスト、セリフ、感情透かしバッジが入った記念アートカード（直角四角形フレーム）が表示されます。
- 「**イラストを再生成**」:
  - 顔写真の特徴（VLM解析結果）、音声の感情解析結果、セリフ、選択シーン設定をそのまま保持した状態で、**新規ランダムSEEDによるComfyUIの画像生成のみを再実行**します（VLMや音声解析をスキップするため約15〜30秒の短時間で別構図・タッチの画像が生成されます）。
- **生成履歴ギャラリー ＆ バージョン切り替え（中央フォーカス・カルーセル表示）**:
  - アートカードの直下に、カード幅（440px）の半分サイズ（210×210px 正方形）のサムネイルが横並びで左から右へ時系列に追加されます。
  - **選択されているサムネイルが常にアートカード中央の真下にピタッと配置**され、その左に「一つ前の画像」、右に「一つ後の画像」が並びます（枠外にはみ出る画像は自動的に非表示）。
  - サムネイルまたは「`◀ Ver. ○ / ○ ▶`」矢印をクリックすると、横方向に滑らかにスライドして対象画像が中央に移動し、**縦方向のズレ（画面の揺れ・高さの変動）は一切発生しません**。
  - **現在選択されているバージョンの画像が、後述の「PNG保存」および「印刷」の対象**となります（再生成後でも最初の1枚目に戻して保存・印刷することが可能です）。
- 「**PNG アートカード保存**」: 生成イラスト単体ではなく、Canon SELPHYのL判フォトプリンター仕様（89×119mm / 300dpi換算 1050×1406 px）に準拠した完全な記念アートカードデータとして保存されます。フチなし印刷時の端部トリミング（オーバースキャン）を防ぐため、外側5%（左右53px、上下70px）に濃紺 `#10141e` の塗り足し余白を確保し、内側のセーフエリア（944×1266 px）に正方形イラスト（896×896 px、アスペクト比 1:1 保持）、直角カード外枠、感情バッジ、シーン名・ブランドロゴ、セリフ枠、日付がすべて収まるようにレイアウトされています。
- 「**その場で印刷する**」: ブラウザの印刷ダイアログが開き、ヘッダーや操作パネル等の不要なUIを完全に排除し、上記L判規格（1050×1406 px、フチなし拡大対策済み）のアートカード画像のみを用紙中央にフィットさせてプリントアウト可能です。
- 「**↻ もう一度あそぶ / 最初の画面へ**」を押すと、セッションがクリーンアップ（サーバー側の一時顔写真も即時破棄）され Step 1 へ戻ります。

## 4. スタッフ設定メニューと各項目

画面右上の「**スタッフ設定**」ボタンをクリックすると、管理者用モーダルが開きます。

### ① マイク ＆ カメラ設定タブ
- **使用カメラ (videoinput)**: 接続されているWebカメラを切り替えます。
- **使用マイク (audioinput)**: 接続されているマイクデバイスを切り替えます。
- **感情分析エンジン・モード切替 (`emotion_mode`)**:
  - `従来モード (SenseVoice + 声量5段階判定)` (`"standard"`): 声のボリューム（dBFS）と SenseVoice の基本感情タグで判定します。
  - `詳細感情モード (15次元プロトタイプ類似度＆2階層方式：基本6表情＋声質ニュアンス修飾2種 / librosa)` (`"detailed_12"`): librosa(ISC)・scipy/numpy(BSD) のみで、Jitter を除外した15項目の音響物理特徴量と基礎6指標（Arousal / Dominance / Valence / 息漏れ(HNR) / Shimmer / 声の高さ・語尾）、および棒読み基準からの物理変化量（`baseline_deltas`）を算出し、`storyweaver_emotion_prototypes.json` に定義された各感情の重心ベクトル（`centroid_z`）との **重み付きユークリッド距離（Gaussian Similarity: `score = 100.0 * exp(-alpha * dist_sq)`）** により **2階層感情モデル（基本表情6種の排他選択 ＋ 声質ニュアンス修飾2種の条件発動 ＋ Arousal連動の重みスケーリング）** へ変換します（商用利用可。SenseVoice の感情タグを Valence バイアスおよび対応感情への軽微な加算ボーナス `+5.0pt` として使用）。
    - **第1階層（基本表情6種・排他選択）**: `joy`（歓喜・笑顔）、`burning`（情熱・怒気・叫び）、`sorrow`（哀愁・切なさ）、`surprise_fear`（驚愕・怯え）、`confident`（不敵・自信・クール）、`serene`（穏やか・優しさ）。相反する基本表情の同時ブレンドによる描画破綻を防ぎます（無音入力時は自動的に `serene`・重み `0.85`・修飾なしへ安全にフォールバック）。
    - **第2階層（声質ニュアンス修飾2種・条件発動）**: `sultry_modifier`（色気・吐息ニュアンス）、`bashful_modifier`（照れ・上ずりニュアンス）。プロトタイプ類似度スコアが閾値（60.0pt以上）を満たしたときのみ副感情としてブレンドされ、平常発声での誤爆を防ぎます（未発動時は `none_modifier`［ストレート表現・修飾なし］）。
    - 解析は 1 回約 0.015〜0.03 秒、サーバ起動時のウォームアップに初回のみ数秒〜約 30 秒かかります。
  - `2-Step ハイブリッドモード (Qwen2-Audio-7B 4bit + Semantic Bridge + Gemma 4 e2b)` (`"qwen2_audio_hybrid"`):
    - **Step 1（聴覚知覚）**: 話者のベースライン音量を基準とした控えめな増幅（ピーク上限 `-3.0 dBFS`）を適用した16kHz音声波形を `Qwen/Qwen2-Audio-7B-Instruct`（4bit NF4量子化、VRAM約6GB）に入力し、シンプルな英語プロンプト（`What is the emotion of the speaker and does the speaker whisper or shout?`）で声の感情と発声スタイル（`qwen2_perception_en`）を抽出します。Step 1 スタンバイまたは Step 2（顔認識）により `gemma4:e2b` が既に VRAM 上に常駐している場合は再ロードをスキップし、未ロード時のみ裏で非同期にプリロードします。
    - **中間層（Semantic Bridge）**: `voice_emo_analyzer` で抽出した物理音響特徴と個人ベースライン差分（`delta_rms_db`, `delta_pitch_st`, `delta_f0_std_st`, `f0_slope_st`, `delta_centroid_hz`, `breath_ratio`, `shimmer` 等）を5項目の英語意味ラベル（`semantic_bridge_en`）へ変換します。
    - **Step 2（論理統合・0〜5整数採点 ＆ 完了後の Gemma VRAM 解放）**: Step 1 の英語聴覚知覚結果と Semantic Bridge を Ollama（`gemma4:e2b`, `think=False`, `format=STEP2_JSON_SCHEMA`, `keep_alive=0`）に入力し、8感情（基本6＋修飾2）を `0〜5` の整数で採点させた上で `×20`（`0〜100 pt`）に変換します。**Step 3 の音声認識・感情分析が完了した時点で `keep_alive=0` により Ollama (`gemma4:e2b`) の VRAM は即時解放**され、さらに Step 4 の ComfyUI 画像生成実行直前に `unload_qwen2_audio_if_loaded()`（および未解放時のフェイルセーフとしての `unload_ollama_if_loaded()`）で Qwen2-Audio の VRAM も自動解放（約6GB → 10MB未満）されるため、VRAM 16GB 環境での OOM を完全に防止します。
- **ComfyUI ワークフロー (JSON) 切替**:
  - `標準 (FaceDetailer あり / 30+20 steps) (storyweaver_anime_api.json)`: Base生成後に FaceDetailer で表情・目元を高精細に再描画する標準パイプラインです。
  - `高速 (FaceDetailer なし / 30 steps) (storyweaver_anime_nofd_api.json)`: FaceDetailer 工程を省略し、Base KSampler（30 steps）のみで出力する高速パイプラインです。
  - プルダウンを変更すると即座に `PUT /api/config` で `config.json` の `WORKFLOW_PATH` に保存され、以降の画像生成に反映されます。
- **マイク音量キャリブレーション (従来モード用)**:
  - リアルタイム音量メーターを見ながら「BURNING 昇格閾値」スライダーを調整できます（標準: `-12.0 dBFS`）。
- **3点ボイスチェック（基準値＆アンカー登録 / 詳細12感情モード用）**:
  - スタッフ設定モーダル内でも、Step 3 と共通の「**① 棒読み（基準・50pt）**」「**② 張った声（上限アンカー）**」「**③ ささやき声（吐息アンカー）**」の3ボタン（開始/停止トグル・最大6秒自動停止）でキャリブレーションを行えます。
  - 登録状態バッジ（`①棒読み` / `②張り声` / `③ささやき`）および主要特徴量チップ（①基準の RMS / F0 / HNR / Breath / Jitter / Shimmer、および②Power・③Whisperの実測値）がリアルタイムに表示され、Step 3 のパネルと自動同期します。

### ② シーン作り込み (CRUD) タブ
- 展示シーン（プリセット）の追加・編集・削除が可能です。
- 各シーンの「シーン名」「事前セリフ」「背景・世界観プロンプト (Pos) (`scene_prompt`)」「シーン別ネガティブプロンプト (Nega) (`scene_neg_prompt`)」を直接編集し、「**シーン一覧を保存 (presets.json)**」で即時反映されます。
- **シーン別ネガティブプロンプト (`scene_neg_prompt`)**: その世界観に不要な要素（例: ファンタジー背景での `modern buildings, cars, weapons` 等）をシーン単位で排除できます。空欄時は共通ネガティブ（`NEG_BASE`）および外見逆バイアス（`negative_hair_bias`）のみが適用されます。

### ③ システム稼働状態タブ
- SenseVoice、ComfyUI、Ollama の接続状態やアクティブセッション数を確認できます。

## 4.1 画像の作りこみモード（チューニング・ワークベンチ）

画面上部ヘッダーの「🎨 作りこみモード」ボタン、または `http://127.0.0.1:8000/workbench` から、生成画像の品質と本人同一性を最適化するためのチューニング・ワークベンチ画面を利用できます。

### 主な機能とワークフロー
1. **リアルタイム実行ステータスバー (常時表示)**:
   - 「待機中 (IDLE)」「人物画像分析中 (VLM)」「音声録音中」「音声分析中」「画像生成中 (ComfyUI)」の各実行状態と所要秒数、待機VRAMを可視化。
2. **シーン設定 (CRUD)**:
   - `presets.json` に登録されたシーンを選択・編集・保存・新規追加・削除可能。
   - 「シーンプロンプト (`scene_prompt`)」に加え、「シーン別ネガティブプロンプト (`scene_neg_prompt`)」の閲覧・編集・保存に対応。
3. **人物画像 (Face) ＆ 外見分析**:
   - **ローカル画像選択**: ドラッグ＆ドロップまたはファイル選択（「自動で頭髪〜肩クロップを適用する (`auto_crop`)」チェックボックス付き、デフォルトON）。
   - **① カメラで撮影して頭髪〜肩クロップ**: ワークベンチ内でカメラを起動（頭・肩ガイド枠＆カメラ切替付き）し、`POST /api/capture_cropped_face` でクロップ結果をプレビュー確認した上で入力画像（`sw_crop_xxx.jpg`）としてセット可能。
   - **② 撮影済みクロップ画像リストから選択**: `GET /api/captured_faces` により、通常モードやワークベンチで撮影・クロップ保存された画像（最大30件）をサムネイル一覧からワンクリックで選択・セット可能。
   - テスト画像クイック選択、および任意のタイミングでの `POST /api/analyze_face` 実行。
   - VLM抽出の生JSON・各属性（性別、髪型、前髪有無、額露出、眼鏡、髭、目の形 `eye_shape`（tsurime / tareme / narrow eyes）、眉 `eyebrows`）および計測値を確認。目・眉は特徴が明確な場合のみ `physical_traits` に付与されます。
   - `gender_tag`, `physical_traits`, `negative_hair_bias` の各部品を画面上で直接手直し・加筆可能。
4. **音声 (Audio) ＆ 感情分析（＋3点ボイスチェック・生特徴量デバッグ・Qwen2-Audio ハイブリッド）**:
   - **🎙️ 3点ボイスチェック（ベースライン＆アンカー登録）**: セクション上部の折りたたみパネルにて、現在の基準値・アンカー登録状態（`normal` / `power` / `whisper`）および実測チップを確認しながら、その場で①棒読み・②張った声・③ささやき声をマイク録音（開始/停止トグル）またはローカル WAV ファイル選択（`📂 WAV`）で登録できます。エンジン選択ラベル横のバッジ（`#wb-audio-calib-chip`）でも現在の棒読み基準の登録状態（登録済 F0/RMS または 未測定・初期値使用）が常時確認可能です。
   - **セット済み音声の自動再分析連動**: すでにテスト用のセリフ音声がセットされている状態でキャリブレーション（①〜③）を更新すると、自動的に `POST /api/analyze_audio` で再分析が走り、新しいベースライン／アンカーでのスコア変化を即座に確認できます（「🔄 セット済み音声を再分析」ボタンでの手動再実行も可能）。
   - **感情分析エンジンの3モード切り替え**:
     - `detailed_12`: 詳細感情モード（2階層方式：基本6表情＋ニュアンス修飾2種 / librosa・CPU高速）
     - `qwen2_audio_hybrid`: **Qwen2-Audio + Gemma 4 2-Step ハイブリッドモード（Step 1: 4bit Audio知覚 ＋ Step 2: 物理差分 Semantic Bridge × Gemma 4 e2b 採点）**
     - `standard`: 従来モード（SenseVoice + 声量5段階判定）
   - **Qwen2-Audio (Step 1) / Gemma 4 e2b (Step 2) プロンプト調整**:
     - `qwen2_audio_hybrid` 選択時に展開可能なアコーディオンが有効化され、「Step 1: Qwen2-Audio 聴覚質問プロンプト（英語）」および「Step 2: Gemma 4 e2b への追加採点ルール（任意）」を手動編集・調整できます（「初期プロンプトに戻す」ボタンでいつでも初期値に復元可能）。
   - **Qwen2 + Gemma 4 専用結果カード ＆ 英語中間出力インスペクタ**:
     - 「Overall Impression バッジ（`overall_impression_en`）」、推論合計時間・Qwen2使用VRAMチップを表示。
     - **🎙️ Step 1: Qwen2-Audio 感情・発声読み取り結果 (`qwen2_perception_en`)**: Qwen2-Audio が出力した英語の聴覚認識テキストをそのまま確認可能。
     - **📐 Step 2 Input: Gemma 4 e2b 投入物理分析 (`semantic_bridge_en`)**: 個人ベースライン差分から変換され Gemma 4 e2b に渡された5項目の英語物理分析サマリー（Vocal Energy & Volume, Pitch & Intonation, Timbre & Clarity, Breathiness / Whisper Check, Voice Tremor / Hesitation Check）をそのまま確認可能。
     - 「棒読み基準からの物理変化メーター（`baseline_deltas`）」により、声量変化（ΔRMS）、ピッチ変化（ΔPitch）、抑揚変化（ΔF0 Std）、音色明度（ΔCentroid）、澄み具合変化（ΔHNR）、息漏れ倍率（Breath Fold）の増減を左右センターメーターで視覚的に把握可能。
     - 2階層感情（Primary / Nuance）および8感情スコア一覧（基本6感情＋修飾2種、0〜5採点×20＝0〜100pt）を直感的に確認できます。
   - WAVファイルセットまたはブラウザマイク録音（16kHzモノラルWAV・音量メーター付き）の2系統に対応し、内蔵プレイヤーでその場で試聴可能。
   - **🔬 生特徴量 (`raw_features` 15項目 vs 現在ベースライン) の展開表示**: `detailed_12` モード時、「📊 基礎音響指標 ＆ 全8項目（基本6＋修飾2）＆ 生特徴量を展開」を開くと、6基礎指標・8感情スコアに加えて、抽出された生特徴量15項目（`rms_p90_db`, `peak_db`, `centroid_hz`, `rolloff_hz`, `flatness`, `onset_rate`, `low_band_ratio`, `f0_median_hz`, `f0_std_st`, `f0_iqr_st`, `f0_delta_st`, `f0_slope_st`, `hnr_db`, `breath_ratio`, `shimmer` ※`jitter`除外）と現在ベースラインの対比表を確認できます。
   - 確定セリフ（`script_text`）と表情プロンプト（`expression_prompt`）の直接編集（本番環境と同様に分析完了時に自動セットされ、手動での加筆・微調整が可能）。
5. **ComfyUI 3系統プロンプト統合 ＆ 画像生成**:
   - **使用ワークフロー JSON 選択**: ヘッダーバーのプルダウンから、生成に使用するワークフローJSON（`storyweaver_anime_api.json`［FDあり］／`storyweaver_anime_nofd_api.json`［FDなし］）を実行ごとに切り替えて比較できます。FaceDetailer なし（`has_fd: false`）を選択中は、`Node_Pos_FD` (Node 32) の入力欄と案A/案B切替ボタンが自動的に無効化（`FDなしJSON選択中は未使用` バッジ表示）されます。
   - **🧹 Qwen2 VRAM解放ボタン**: 画像生成開始ボタン（`#wb-btn-start-generate`）の左隣に配置。Qwen2-Audio 推論後に掴んでいる GPU VRAM（約6GB）をワンクリックで即座に解放し、ComfyUI の大容量サンプリングおよび FaceDetailer 実行用メモリ（11〜12GB）を確実に確保できます。
   - 変更に連動して自動組み立て（トグル切替可）または手動再構築。
   - `Node_Pos_Base` (Node 5), `Node_Neg_Base` (Node 6: `{negative_hair_bias}, {scene_neg_prompt}, {NEG_BASE}` の順で空でない要素を自動結合), `Node_Pos_FD` (Node 32) の直接編集（FaceDetailer 案A/案B のワンクリック切り替え対応）。
   - 「画像生成を開始」ボタンにより `POST /api/generate_custom`（`workflow_path` 指定付き）でComfyUIへ注入・実行し、大画面プレビュー、PNG保存、セッション内履歴からプロンプトおよび使用ワークフローJSONのワンクリック復元が可能。

## 6. 停止手順（終了時）

展示終了時やメンテナンス時は、以下の順序で正常停止してください。

1. **ブラウザを閉じる**: 操作画面を閉じます。
2. **FastAPI サーバーの停止**:
   - サーバーを実行しているコンソール画面で `Ctrl + C` を入力します。
   - `Application shutdown complete.` と表示され、プロセスが終了したことを確認します。
3. **ComfyUI の停止**:
   - ComfyUI のコンソールで `Ctrl + C` を押すか、Pinokio から Stop を実行します。
4. **一時ファイルの自動確認**:
   - サーバー停止時に一時画像や音声ファイルは自動クリーンアップされます。次回起動時にも自動スイープが実行されます。

## 7. トラブルシューティング

| 現象 | 主な原因 | 対処方法 |
| :--- | :--- | :--- |
| **起動時に `ModuleNotFoundError` が出る** | 必要ライブラリの未インストール | `pip install librosa soundfile sounddevice` を実行してください（opensmile / transformers は商用化に伴い不要）。 |
| **画面が `System Error` / サーバーに繋がらない** | FastAPI サーバーが未起動 | `python -m uvicorn server:app --port 8000` が起動しているか確認してください。 |
| **画像生成がタイムアウトする（504エラー）** | ComfyUI が起動していない、または高負荷 | `http://127.0.0.1:8188` にアクセスできるか確認し、ComfyUI を再起動してください。 |
| **顔が認識されない（422エラー）** | ガイド枠から顔が外れている、手で隠れている | ガイドの楕円内に顔を正面に向けて収め、再度撮影してください。 |
| **音声認識セリフが空になる** | マイクが無音、または入力デバイス不一致 | スタッフ設定でマイクデバイスが合っているか確認し、メーターが反応するかテストしてください。 |
| **詳細12感情モードでスコアが極端** | ベースライン未登録、または周囲の環境雑音 | スタッフ設定から静かな環境で「棒読み基準値」を再録音・登録してください。 |
